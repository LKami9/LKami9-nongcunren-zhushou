# LKami9农村人助手

Omni 在线模块。跨服或超域传送落地后，自动把你送到**海都（利姆萨·罗敏萨）**的大水晶。

只做传送，不模拟按键、不寻路、不改内存。

## 它解决的具体问题

超域传送（国服）的流程是：**关客户端 → 网页申请 → 重开客户端登录目标大区**。
落地位置是创建角色时所选职业对应的主城，不一定是海都，而集合、买东西、雇员都常在海都。

这个模块做的事就一句话：**发现你换了服务器，落地稳定后，如果不在海都就把你传送过去。**

## 判定逻辑

每个游戏帧检查一次，状态推进是四步：

1. **对比服务器**：从文件读出上次记录的服务器 ID，和当前 `PlayerState.CurrentWorld` 比。
2. **判定是否跨服**：不一样就触发。默认只认**大区变更**（拿 `World.DataCenter` 逐行比较），同大区跨服可以在设置里放开。
3. **等落地**：先等设置的秒数（默认 2 秒），再检查 `BetweenAreas`／任务事件／过场这类状态，全部不忙才继续。最多等 120 秒，超时放弃，不会卡死。
4. **传送**：当前区域名不含「利姆萨 / Limsa」才动手，走游戏原生 `Telepo`，用已解锁的大水晶。

传送发出后还会盯 90 秒，确认是否真的到了海都。到了显示「已到达海都」，没到会告诉你可能被中断。

## 为什么服务器记录要自己存文件

这是全模块最关键的一处设计。超域传送必须**关掉客户端**才能申请，重开后插件跟着重启。
如果把「上次的服务器」放在内存或宿主配置里，重启后大概率是空的 —— 于是第一次读到当前服务器只会去记录，不会触发，**功能在最需要它的场景下正好失效**。

所以记录写在：

```
%APPDATA%\XIVLauncherCN\pluginConfigs\OmniToolbox\AutoLimsa.state
```

纯文本，一个数字（World 行 ID）。删掉它就是「下次登录重新学习当前服务器」。

## 设置项

| 项 | 默认 | 说明 |
|---|---|---|
| 落地后自动传送 | 开 | 关掉后只提示，不动手 |
| 只在大区变更时触发 | 开 | 取消勾选则同大区跨服也触发 |
| 落地后等待 | 2.0 秒 | 跨服加载慢就往上调 |

界面里还能看到当前服务器、当前区域、已记录的服务器，以及两个按钮：**立即前往海都**（手动跑一次）、**重新识别水晶**（水晶没识别出来时点）。

## 命令

```
/L9HD GO      立即传送一次
/L9HD rset    清掉服务器记录
```

短命令在模块**启用时注册、停用时注销**，不占着不放手。如果 `/L9HD` 已经被别的插件占了，会写一行日志、界面也会提示，这时仍然可以用长命令 `/omni AutoLimsaOnArrival go`。
`rset` 之外也收了 `reset`，打顺手了不会没反应。

## 已知限制

- **海都大水晶必须已解锁**。没解锁就传送不了，界面会明说「水晶可能未解锁」，不会静默失败。
- **不做城内移动**。要把你从下层甲板送到上层甲板，那是城内以太网，本模块不碰。
- **不管副本**。在副本里跨服不存在，传送也会被游戏自己拒绝。
- 大水晶 ID 是按名称匹配出来的，没有硬编码。换语言客户端（中/英）都能认；如果哪天认不出来，会话界面里那个「重新识别水晶」按钮看日志。

## 安装

在线模块：把本目录推到仓库根，Omni 读根目录的 `TreeHouseModules.json`。

本地测试：把 `AutoLimsaOnArrival.cs` 复制到

```
%APPDATA%\XIVLauncherCN\pluginConfigs\OmniToolbox\TreeHouseLocal\Sources\
```

然后在「树树妙妙屋 → 本地」里启用。

## 改代码之后

`TreeHouseModules.json` 里的 `Sha256` 算的是**文件实际字节**，改一个空格都会变。改完要重算并抬 `Version`，否则已装用户不会更新：

```powershell
$h = (Get-FileHash AutoLimsaOnArrival.cs -Algorithm SHA256).Hash
# 把 $h 填进 TreeHouseModules.json 的 Sha256，并把 Version 加一
```

`.gitattributes` 里锁了 `* -text`，避免 Windows 提交时把 LF 换成 CRLF 导致远端校验失败。
